Full-Stack Security & Architecture Checklist

Verified against PDF specification (Modules 8, 9, 10, 11)

Frontend (Angular) Best Practices

  • Standalone components for all new code
  • Signals for reactive state (no manual change detection)
  • Centralized SignalStore single-source-of-truth
  • @defer blocks for heavy component chunk splitting
  • Interceptors for authentication, XSRF & error handling
  • Route & Role Guards for protected routes

Backend (.NET) Best Practices

  • BCrypt unique salted password hashing
  • ASP.NET Core Identity with lockout protection
  • JWT short-lived authentication (15m)
  • Single-use refresh token rotation & theft detection
  • Resource-based authorization policies
  • CORS policies & Security headers
  • Endpoint rate limiting (429 Retry-After)
